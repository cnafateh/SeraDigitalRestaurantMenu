## خلاصهٔ خیلی کوتاه

- یک ایمیج Docker، خروجی React/Vite و API مبتنی بر ASP.NET Core را روی پورت داخلی **80** سرو می‌کند.
- داده‌های مکان‌ها و آیتم‌های منو در **PostgreSQL موجود شما** نگه‌داری می‌شوند. Compose این پروژه کانتینر PostgreSQL نمی‌سازد.
- کانتینر در Compose به شبکهٔ خارجی `DB_NETWORK` می‌پیوندد و `DB_HOST` را روی همان شبکه پیدا می‌کند. Compose تولیدی به شبکهٔ `NPM_NETWORK` نیز می‌پیوندد و alias آن `sera-menu` است.
- عکس‌های اولیه در ایمیج (`/images/...`) هستند؛ آپلودهای پنل در volume مسیر `/app/uploads` قرار می‌گیرند.
- ورود پنل با یک رمز مشترک `SERA_ADMIN_PASSWORD` و cookie انجام می‌شود. سیستم حساب کاربری چندنفره، سفارش، پرداخت و سبد خرید در پیاده‌سازی فعلی وجود ندارد.
